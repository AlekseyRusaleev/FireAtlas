ПОЖАРНЫЙ АТЛАС — краткая инструкция

1. УСТАНОВКА
   - Распакуйте архив в любую папку (например C:\FireAtlas).
   - Запустите FireAtlas.exe.
   - При первом запуске Windows может спросить разрешение — разрешите.
   - Нужен Microsoft Edge WebView2 (обычно уже есть в Windows 10/11).
     Если программа не открывается: https://developer.microsoft.com/microsoft-edge/webview2/
   - В архиве нет готовой базы и чужих меток — только программа и пустой шаблон FireData.
     Настройки и индекс на каждом компьютере свои.

2. ПАПКА БАЗЫ
   Создайте папку, например D:\FireData, со структурой:

     FireData\
       KMZ\
       Информационные карточки\

   В программе: Настройки → «Путь к базе данных» → Обзор… → выберите FireData → Сохранить.

3. ВОДОИСТОЧНИКИ (ИППВ)
   - Настройки → «Добавить файлы KML / KMZ…» (или «Добавить из папки…»),
     либо скопируйте .kmz/.kml в FireData\KMZ\.
   - Нажмите «Переиндексировать базу».

4. ИНФОРМАЦИОННЫЕ КАРТОЧКИ
   Положите папки объектов в FireData\Информационные карточки\
   и снова нажмите «Переиндексировать базу».

5. КАРТА (ОФЛАЙН)
   В дистрибутиве для НСО уже вшиты карты пунктов отрядов ФПС:
   Новосибирск, Бердск, Искитим, Куйбышев, Краснообск, Карасук, Мошково.
   - Настройки → выберите город из списка установленных карт.
   - Дополнительно: «Импорт ZIP с флешки…» или «Скачать» (нужен интернет).
   - Без интернета карта и документы работают из локальных пакетов / FireData.

6. ГОРОД ПО УМОЛЧАНИЮ
   Укажите город в поле «Город по умолчанию» и нажмите «Найти» / Enter.
   Поиск адресов ограничен радиусом 50 км вокруг этого города
   (при наличии интернета; офлайн — по координатам карточки / локальной карте).

7. МЕТКИ НА КАРТЕ
   На вкладке «Карта» можно самостоятельно ставить свои метки:
   - нажмите «Поставить метку»;
   - щёлкните по нужному месту на карте;
   - укажите название и при необходимости комментарий.
   Метки сохраняются в файл user_markers.kml в папке базы.

8. РАБОТА
   - Вкладка «Карта» — поиск адресов и водоисточников, свои метки.
   - Вкладка «Информационные карточки» — поиск и открытие документов.
   - Вкладка «О программе» — контакты разработчика.
   - Ctrl+F — поиск, F2 — карта.

При переносе на другой компьютер скопируйте папку программы (с maps\)
и папку базы FireData. Либо импортируйте ZIP карты и укажите FireData заново.

======================================================================
LINUX (Ubuntu / Debian и совместимые)

1. УСТАНОВКА (рекомендуется: portable-бинарник + установщик)
   - Скачайте с https://geo.infocardmchs.ru/updates/ два файла:
       FireAtlas-<версия>-linux-x86_64
       install-fireatlas-linux.sh
   - Выполните:
       chmod +x install-fireatlas-linux.sh FireAtlas-<версия>-linux-x86_64
       ./install-fireatlas-linux.sh
   - Программа появится в меню приложений «Пожарный Атлас».
   - Нужны WebKitGTK и GTK (обычно уже установлены):
       sudo apt-get install -y libwebkit2gtk-4.1-0 libgtk-3-0

2. ДРУГИЕ ВАРИАНТЫ
   - AppImage (один файл):
       chmod +x FireAtlas-<версия>-linux-x86_64.AppImage
       ./FireAtlas-<версия>-linux-x86_64.AppImage
     На Ubuntu 24.04 может понадобиться FUSE: sudo apt install libfuse2t64
   - DEB (системная установка):
       sudo apt install ./FireAtlas-<версия>-linux-x86_64.deb
     Автообновление в этом варианте требует прав root — обновляйтесь новым .deb.

3. ОБНОВЛЕНИЕ С СЕРВЕРА
   Приложение само проверяет latest.json и предлагает обновление (баннер при
   запуске и кнопка в «О программе»). В варианте portable/AppImage новая версия
   скачивается и ставится автоматически, программа перезапускается.

4. ГДЕ ХРАНЯТСЯ ДАННЫЕ
   Настройки и индекс: ~/.local/share/ru.fireatlas.app/
   Папка базы FireData и скачанная карта — на каждом компьютере свои.
