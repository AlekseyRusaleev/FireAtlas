ПОЖАРНЫЙ АТЛАС — краткая инструкция

1. УСТАНОВКА
   - Распакуйте архив в любую папку (например C:\FireAtlas).
   - Запустите FireAtlas.exe.
   - При первом запуске Windows может спросить разрешение — разрешите.
   - Нужен Microsoft Edge WebView2 (обычно уже есть в Windows 10/11).
     Если программа не открывается: https://developer.microsoft.com/microsoft-edge/webview2/

2. ПАПКА БАЗЫ
   Создайте папку, например D:\FireData, со структурой:

     FireData\
       KMZ\
       Информационные карточки\

   В программе: Настройки → «Путь к базе данных» → Обзор… → выберите FireData → Сохранить.

3. ВОДОИСТОЧНИКИ (ИППВ)
   - Настройки → «Добавить файлы KML / KMZ…» (или «Добавить из папки…»),
     либо скопируйте .kmz/.kml в FireData\KMZ\.
   - Нажмите «Переиндексировать базу».

4. ИНФОРМАЦИОННЫЕ КАРТОЧКИ
   Положите папки объектов в FireData\Информационные карточки\
   и снова нажмите «Переиндексировать базу».

5. КАРТА
   - В настройках введите название своего города и радиус (км).
   - Нажмите «Скачать» (нужен интернет; загрузка идёт в фоне).
   - После окончания откройте вкладку «Карта».

6. ГОРОД ПО УМОЛЧАНИЮ
   Укажите город в поле «Город по умолчанию» и нажмите «Найти» / Enter.
   Поиск адресов ограничен радиусом 50 км вокруг этого города.

7. РАБОТА
   - Вкладка «Карта» — поиск адресов и водоисточников, метки.
   - Вкладка «Карточки тушения» — поиск и открытие документов.
   - Ctrl+F — поиск, F2 — карта.

При переносе на другой компьютер достаточно скопировать FireAtlas.exe
и папку базы FireData. Карту каждый компьютер скачает сам (кнопка «Скачать»).
