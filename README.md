# Пожарный Атлас (FireAtlas)

Настольное приложение для пунктов связи пожарной охраны: поиск ИППВ, информационные карточки Infocard, локальная карта OSM, адресный поиск.

Текущая версия клиента: **0.1.33**.

## Стек

- **Tauri 2** (Rust) — desktop runtime
- **React + TypeScript + Vite** — UI
- **SQLite + FTS5** — индекс и поиск
- **Leaflet / OpenStreetMap** — локальные пакеты городов + онлайн-подложка
- **Свой Nominatim** — `https://geo.infocardmchs.ru` (адресный поиск и крупная нумерация домов)

## Установка

Новым компьютерам ставьте установщик, **не копируйте** рабочую папку с `FireData` и настройками:

**https://geo.infocardmchs.ru/updates/FireAtlas-Setup.exe**

Установщик кладёт `FireAtlas.exe` и `WebView2Loader.dll` в `%LOCALAPPDATA%\FireAtlas\` (латиница, без прав администратора). При необходимости доставляет Microsoft Edge WebView2 Runtime.

Уже установленные копии обновляются из программы: **О программе → Проверить обновления**. Канал: `https://geo.infocardmchs.ru/updates/latest.json` + portable ZIP.

## Быстрый старт

1. Запустите **Пожарный Атлас** (`FireAtlas.exe`).
2. **Настройки** → город по умолчанию, режим карточек и водоисточников (локально / сервер Infocard).
3. Для локальной базы: укажите путь к папке `FireData` → **Сохранить** → добавьте KMZ и карточки → **Переиндексировать**.
4. **Скачать** пакет карты (радиус 5–80 км). Если круг меньше города — за его границей остаётся онлайн-карта, метки не висят в пустоте.
5. Поиск: адрес («Найти адрес») или название объекта Infocard. Клик по результату переносит карту; PDF карточки открываются в программе.

Настройки, индекс и скачанные карты хранятся на каждом компьютере отдельно (AppData). Архив/установщик **не содержит** чужую базу.

Интернет нужен для: скачивания пакета карты, адресного поиска, нумерации домов, Infocard и проверки обновлений. Уже скачанная карта и локальные KMZ/карточки работают offline.

## Структура локальной базы

```
FireData/
├── KMZ/                      # .kml / .kmz с ИППВ
└── Информационные карточки/  # папки объектов (docx, pdf, jpg, …)
```

После указания пути приложение создаёт `atlas.db` в AppData. Пакеты карты — в AppData (`maps/`).

## Возможности

- Импорт KML/KMZ, типы ИППВ (гидрант / водоём / башня / пирс)
- **Источник водоисточников**: локальный KMZ **или** метки Infocard (в приложении — только просмотр)
- Правка локальных ИППВ: перенос и удаление с записью в рабочий KMZ/KML
- **Источник карточек**: локальная папка, сервер Infocard или оба
- Поиск Infocard по названию, улице и дому; клик по карточке ведёт на адрес на карте
- Локальная карта OSM; за границей скачанного круга — онлайн-подложка Carto
- Поиск адреса → жёлтая метка → карточки по адресу + ближайшие ИППВ
- Подсказки адресов; геокодер сначала свой Nominatim (кэш, без ожидания запасных сервисов)
- **Крупная нумерация домов** (свой Nominatim, зум ≥ 15)
- **Обновления**: маленькое окошко в углу (не полоска на весь экран); файлы подменяются до закрытия окна; лишние ярлыки на рабочем столе не создаются
- На узком мониторе панель объекта открывается **поверх карты** справа, с кнопкой «Закрыть»
- Свои метки на карте (в режиме локальных водоисточников)
- Просмотр JPG, PDF и DOCX внутри программы; PDF Infocard — после конвертации на сервере
- Избранное и история
- Горячие клавиши: `Ctrl+F` поиск, `F2` карта

## Свой геокодер

FireAtlas остаётся **локальным** по данным (карта, ИППВ, карточки, метки).  
Адресный поиск и номера домов идут на **свой сервер**.

| Компонент | Адрес / заметка |
|-----------|-----------------|
| Nominatim | extract **Кемеровской области** |
| Публичный вход | **https://geo.infocardmchs.ru** |
| Номера домов API | `https://geo.infocardmchs.ru/housenumbers?south&west&north&east&limit` |
| Обновления | `https://geo.infocardmchs.ru/updates/latest.json` + `FireAtlas-Setup.exe` + portable ZIP |
| Клиент | сначала свой Nominatim; Яндекс / Photon / публичный OSM — только если своего результата нет |

Скрипты серверной части: [`server/`](server/) (`housenumbers_api.py`, [`server/updates/`](server/updates/)).

Город в **Настройках** задаёт центр и радиус поиска. Покрытие геокодера = то, что импортировано на сервере.

### Схема

```
FireAtlas (клиент)
  ├─ локально: карта OSM, KMZ/ИППВ, информационные карточки, метки
  └─ HTTPS → https://geo.infocardmchs.ru
              ├─ /search,…     → Nominatim (Кемеровская область)
              ├─ /housenumbers → номера домов на карте
              └─ /updates/     → latest.json + FireAtlas-Setup.exe + portable ZIP
  └─ HTTPS → Infocard API
              ├─ поиск файлов карточек / PDF
              └─ GET /markers → водоисточники с веб-кабинета (режим «сервер»)
```

### Автообновление

1. При старте клиент тихо читает `latest.json` и сравнивает `version`.
2. Если есть новее — маленькое окошко «Обновить» / «Позже» (то же в «О программе»).
3. Уже установленные копии: ZIP → SHA-256 → подмена `FireAtlas.exe` в текущей папке → запуск заново. Ярлыки на рабочем столе не создаются.
4. Новые компьютеры: только установщик `FireAtlas-Setup.exe`.

Выкладка релиза: [`server/updates/README.md`](server/updates/README.md).

| ✓ | FireAtlas → свой геокодер, нумерация домов |
| ✓ | Канал обновлений: NSIS + portable ZIP |
| ✓ | Infocard: карточки, PDF, водоисточники, поиск с карты |
| → | Добавить **Новосибирскую область** в геокодер |
| later | Шире СФО / другие области при большей RAM |

### Почему не «ближайший дом»

Если точный адрес не найден в индексе — **не подставляем чужой дом**.  
Номер на тайле OSM и наличие адреса в геокодере — разные вещи.
