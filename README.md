# Пожарный Атлас

Настольное offline-first приложение для диспетчеров пожарной охраны: поиск водоисточников по KML/KMZ, карточки тушения, карта, единый поиск.

## Стек

- **Tauri 2** (Rust) — лёгкий desktop runtime
- **React + TypeScript + Vite** — UI
- **SQLite + FTS5** — индекс и мгновенный поиск
- **Leaflet / OpenStreetMap** — локальные пакеты городов + онлайн
- Поля ключей Яндекс/2ГИС — опционально

## Локальная карта города (OSM)

1. В настройках укажите путь к базе и сохраните.
2. Выберите город в списке «Пакет локальной карты».
3. Нажмите **Скачать / подготовить пакет** (нужен интернет один раз).
4. Провайдер карты: **Локальная OSM**.

Пакет лежит в `FireData/maps/<city_id>/` (тайлы + `meta.json`).

Чтобы передать в другой город:
- **Сохранить ZIP…** — отдать файл коллегам
- у них: **Загрузить ZIP…** или **Выбрать папку…**

## Структура базы на диске

В настройках укажите корневую папку, например `D:\FireData`:

```
FireData/
├── maps/                # локальные пакеты OSM по городам
│   └── kemerovo/
├── KMZ/
└── Информационные карточки/
```

После указания пути нажмите **Переиндексировать**. Приложение создаст локальный `atlas.db` в AppData.

## Возможности MVP

- Импорт KML/KMZ, определение типа ИППВ (гидрант / водоём / башня / пирс)
- Индекс информационных карточек из папок `/KTP`
- Единый поиск (FTS5) по названию, адресу, номеру, тексту docx
- Карты Яндекса, 2ГИС и OSM; поиск адреса с выделением результата
- Ближайшие ИППВ и пользовательские метки с экспортом в `user_markers.kml`
- Просмотр JPG, PDF и DOCX внутри приложения; старые DOC и Visio открываются внешне
- Избранное и история
- Горячие клавиши: `Ctrl+F` поиск, `F2` карта
